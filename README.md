# ScreenSathi

Responsive ScreenSathi screen-repair website built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Current preview status

The home page follows the supplied reference's white, monochrome layout and page flow. The header uses a ScreenSathi text wordmark, Login and Sign Up controls, and Request a Quote. The repair flow lets visitors select a brand, model, screen issue, contact details, and service preference, then review the request. It includes photo cards for Apple, Samsung, Google Pixel, OnePlus, Xiaomi / Redmi, Vivo, Oppo, Realme, Motorola, and Nothing.

Contact submission, booking, payment, login, Hindi translation, and repair tracking are presentation-only until their real services and business details are configured. The ₹99 amount is described as the booking and inspection fee; the final display repair estimate must be confirmed before work begins. The service area is shown as Ara (Arrah), Bihar.

Image sources and license links are listed in [public/images/SOURCES.md](public/images/SOURCES.md). The hero and repair images are stored locally so they do not depend on image hotlinks at runtime.
